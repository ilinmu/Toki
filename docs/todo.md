# 待办

记录明确推迟的工作。每项写清现状与动手位置；不排期。

## T1 人物与地点视图

- **现状**：没有面部聚类，也没有地理逆编码，侧栏没有这两个入口；照片只有 EXIF 的 GPS 坐标，没有「地点名」。
- **要做的事**：先定识别来源（本地聚类 / 云端服务 / 手工标注），再加 `Photo.People []string` 与地点词表；
  视图层复用 `ui_library.go` 的卡片与网格，地图可以画简化海岸线，或接系统地图。
- **不做的理由**：没有识别来源时，这两页只能是假数据。

## T2 独立编辑页（画布 + 滤镜预设 + 保存副本）

- **现状**：编辑在「查看详情」页右侧面板里，三组：裁剪拉直 / 旋转翻转 / 色彩（曝光、对比度、饱和度、色温、暗角）。
  没有滤镜预设，没有「保存副本」，历史是每张照片的撤销栈（上限 50）。
- **要做的事**：加 `mode` 的第四种（编辑页），复用 `editPanel` 的控制项；滤镜预设定义成 `EditState` 的命名组合；
  「保存副本」要决定写文件（复制 + 渲染）还是只建库内副本。

## T3 相册总览页（封面卡片墙）

- **现状**：相册只在侧栏列出，点进去是筛选后的照片墙；新建相册对话框已有（名称 + 说明）。
- **要做的事**：加一个 `nav == "albums"` 的视图，按 `AlbumList()` 画卡片，封面用第一张照片的缩略图。

## T4 拖放：照片拖到侧栏相册

- **现状**：只能用「加入相册」对话框或检查器里的下拉。
- **要做的事**：MyGo 有 `Draggable` / `DragOver` / `Drop`，把卡片的拖拽负载设为照片路径集合，
  相册行接受放置后调 `Library.AddToAlbum`。

## T5 导入窗口（拖放区 + 文件列表 + 进度）

- **现状**：用系统文件夹选择器选择要监视的文件夹（只索引，不复制、不移动原文件），没有拖放区与进度。
- **要做的事**：先决定拖进来的文件是「复制到库目录」「原地监视」还是「只登记路径」，再谈 UI。

## T7 更多图片格式

- **现状**：JPEG / PNG / GIF / BMP / WebP / TIFF；HEIC、AVIF、相机 RAW 不支持。
- **要做的事**：评估纯 Go 解码器；没有的话，决定是否接受 cgo 依赖或调用系统转换服务。
